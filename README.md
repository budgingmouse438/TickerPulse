# TickerPulse

A web app for watching stock prices via [Alpaca](https://alpaca.markets/) market
data. Click a ticker to give it a live "pulse" — a real-time Alpaca websocket
feed — while the rest of your watchlist updates in the background every ~10s
via REST polling.

See [DESIGN.md](./DESIGN.md) for the architecture and rationale.
